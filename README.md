# AgentKey

**AgentKey** 是一个面向 Android 的本地优先 Agent 工作台原型，基于 Expo、React Native 与 TypeScript 构建。它演示了用户自建 API 供应商、多模型多密钥轮询、远程 MCP 工具、本地记忆、受限沙盒终端和本地技能包等能力。

> 这是一个原型项目。请在接入真实服务前自行完成威胁建模、密钥管理审计、服务端鉴权与生产环境测试。

## 功能概览

| 模块 | 能力 |
| --- | --- |
| API 与模型 | 自定义兼容 API 供应商；同一供应商下维护多个模型；每个模型拥有独立多密钥池。 |
| 密钥路由 | 支持优先级、严格循环和最少负载策略；失败、限流或认证异常可触发冷却。 |
| MCP 工具 | 支持 HTTP 与 SSE 远程 MCP 服务发现、调用、参数脱敏、调用前确认和高风险工具记住授权。 |
| 本地上下文 | 本地记忆库、启停与检索；不将密钥或认证令牌写入任务轨迹。 |
| Token 统计 | 并列展示本地估算与兼容 API 返回的真实 usage，并支持按日期、供应商和模型筛选。 |
| 受限终端 | 仅提供虚拟工作区中的白名单命令；高风险命令不执行，低风险 `pwd`/`ls` 可选自动批准。 |
| 本地技能 | 支持内置和自定义技能、任务关键词匹配，以及经过校验的 JSON 技能包导入、导出和恢复。 |

## 本地运行

安装 Node.js 22+ 与 Expo 开发环境后，在项目根目录执行：

```bash
npm install
npm run android
```

如需在浏览器调试：

```bash
npm run dev:metro
```

## 验证命令

```bash
npm run check
npm run test
npm run lint
npx expo export --platform android
```

## 安全边界

API 密钥与 MCP 认证令牌仅在设备端保存；原生端使用 `expo-secure-store`，网页预览使用本地存储降级。界面仅展示尾号或脱敏摘要。技能包不含密钥、认证令牌、设备标识或运行轨迹；导入会校验格式并仅恢复技能描述字段。

MCP 服务由使用者自行配置。启用远程服务、调用工具或分享本地技能包前，请确认其来源与权限范围。
